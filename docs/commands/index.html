Command Reference

This document provides the complete command syntax, parameters, and examples for all supported Google Workspace services in HERMES CLI.

Gmail Service (hermes gmail)

Read, compose, search, and manage email threads:

Gmail Examples
# List recent messages from your inbox
hermes gmail list --max-results 10

# Search emails with Gmail query syntax
hermes gmail search "has:attachment larger:5M"

# Read a specific email message
hermes gmail get <MESSAGE_ID>

# Send a new email
hermes gmail send --to "team@example.com" --subject "Release Plan" --body "Attached below."

# Create a draft message without sending
hermes gmail draft create --to "partner@example.com" --subject "Proposal" --body "Draft notes..."

# Apply a label to an email thread
hermes gmail label add <MESSAGE_ID> --label "Work/Priority"

# Mark email as read or unread
hermes gmail mark read <MESSAGE_ID>
hermes gmail mark unread <MESSAGE_ID>

Google Calendar (hermes calendar)

Manage calendars, view agendas, and schedule events:

Calendar Examples
# Quick view of today's schedule
hermes calendar today

# View tomorrow's schedule
hermes calendar tomorrow

# View upcoming events for the next 7 days
hermes calendar upcoming --days 7

# List all user calendars
hermes calendar list

# Create a calendar event
hermes calendar create-event \
  --summary "Sprint Review" \
  --start "2026-10-01 14:00" \
  --duration 45 \
  --attendees "dev1@example.com,dev2@example.com"

# Delete a calendar event
hermes calendar delete <EVENT_ID>

# Query calendar availability by date range
hermes calendar by-range --start "2026-10-01" --end "2026-10-05"

Google Sheets (hermes sheets)

Read and manipulate spreadsheet tables directly:

Sheets Examples
# List spreadsheets accessible to your account
hermes sheets list

# Read tabular range from a spreadsheet
hermes sheets read <SPREADSHEET_ID> --range "Quarterly!A1:D20"

# Append a row of values
hermes sheets append <SPREADSHEET_ID> --range "Log!A:C" --values "2026-09-27,Deploy,Success"

# Create a brand new spreadsheet in Google Drive
hermes sheets create --title "Q4 Infrastructure Metrics"

Google Docs (hermes docs)

Query document text structures and compose documents:

Docs Examples
# List accessible Google Docs documents
hermes docs list

# Read text contents of a document
hermes docs read <DOCUMENT_ID>

# Create a new document
hermes docs create --title "Architecture Specification"

# Append content to an existing document
hermes docs append <DOCUMENT_ID> --text "Section 4: Threat Model Analysis"

Google Meet (hermes meet)

Generate meeting spaces and conference links:

Meet Examples
# Create a new instant Google Meet space
hermes meet create --topic "Architecture Sync"
# Output returns meeting URI (e.g., https://meet.google.com/abc-defg-hij)

# List meeting spaces
hermes meet list

# Get meeting space details
hermes meet get <MEETING_SPACE_NAME>

Google Forms (hermes forms)

Inspect form questions and read respondent submissions:

Forms Examples
# List forms accessible to your account
hermes forms list

# Inspect form metadata and questions schema
hermes forms get <FORM_ID>

# Fetch respondent submissions
hermes forms responses <FORM_ID> --format json

Output Formats & Scripting Integration

Format command outputs for terminal reading or automate pipelines using --format:

JSON Format with jq

bash
hermes calendar today --format json | jq '.[] | {summary: .summary, start: .start}'

CSV Format for File Export

bash
hermes sheets read <SPREADSHEET_ID> --range "A1:E50" --format csv > report.csv
