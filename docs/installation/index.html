Installation Guide

HERMES GSuite CLI is distributed as a lightweight, standard Python package published on PyPI. It runs locally without external daemon services.

System Requirements

Before installing HERMES CLI, verify that your environment satisfies the prerequisites:

  • Operating System: Linux (Ubuntu, Debian, Fedora, Arch), macOS (11+), or Windows 10/11.
  • Python Version: Python 3.8, 3.9, 3.10, 3.11, or 3.12.
  • Network Access: Direct outgoing HTTPS (port 443) access to Google APIs (*.googleapis.com).

Standard Installation via pip

Install the package directly into your current Python environment:

bash
pip install hermes-cli

Recommended: Isolated Virtual Environment

We recommend creating an isolated virtual environment to prevent dependency conflicts with your system Python packages:

Linux & macOS

bash
# Create virtual environment
python3 -m venv ~/.hermes-env

# Activate virtual environment
source ~/.hermes-env/bin/activate

# Install HERMES CLI
pip install hermes-cli

Windows (PowerShell)

powershell
# Create virtual environment
python -m venv $HOME\.hermes-env

# Activate virtual environment
& $HOME\.hermes-env\Scripts\Activate.ps1

# Install HERMES CLI
pip install hermes-cli

Verifying the Installation

Verify that the binary is available in your shell's PATH:

bash
$ hermes --version
hermes, version 0.1.0

$ hermes --help
