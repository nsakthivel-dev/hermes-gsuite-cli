Common Troubleshooting Scenarios

“OAuth client configuration not found”

Ensure your credentials.json file is placed in ~/.config/gsuite-cli/credentials.json, or export the environment variable HERMES_GOOGLE_CLIENT_SECRET=/path/to/credentials.json.

“Access blocked: This app has not been verified”

If your Google Cloud OAuth consent screen is in Testing status, make sure your Google account email is added under Test users in Google Cloud Console. Once verified by Google, any user can authenticate without warning.

“Permission denied (403) / Insufficient Scopes”

Run hermes auth login --force to initiate a fresh OAuth 2.0 flow and ensure all necessary permission checkboxes are checked on Google's consent screen.
